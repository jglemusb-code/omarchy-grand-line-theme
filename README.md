# Grand Line

An Omarchy theme inspired by One Piece: deep ocean surfaces, straw-gold focus
states, crimson sails, and a hand-painted night voyage wallpaper.

## Install

Copy this directory into `~/.config/omarchy/themes/grand-line`, then apply it:

```bash
omarchy theme set grand-line
```

The included wallpaper is an original pirate-ocean illustration created for
this theme. It contains no franchise characters or logos.

## Palette

- Ocean navy surfaces keep windows and terminals calm and readable.
- Straw gold marks focus, selection, and active controls.
- Crimson, coral, teal, and blue carry the ANSI colors through terminals and
  editors.
